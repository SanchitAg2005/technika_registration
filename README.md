# technika_registration — Previous Iteration

Previous iteration of the Technika event registration backend.

## What This Repository Was

This was an earlier version of the event registration backend for Technika. It shares the same general data model (participants, events, teams, registrations, Google Sheets sync) as later iterations but represents an earlier stage of development.

## Project Status

This repository is a **previous iteration** and is not the current Technika registration platform.
